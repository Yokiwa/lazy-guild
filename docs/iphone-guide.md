# iPhone 使用指南

> English version below.

需要 **iOS 16.4 或更高版本**（设置 → 通用 → 关于本机 → iOS 版本）。

## 1. 添加到主屏幕

1. 用 **Safari** 打开懒人公会的网址（其他浏览器不行）。
2. 点底部的 **分享** 按钮（方框加向上箭头）。
3. 往下滑，选 **添加到主屏幕**，再点 **添加**。
4. 之后**都从主屏幕的图标打开**。只有这样打开，才能收到通知，也能离线使用。

## 2. 开启通知

1. 从主屏幕打开懒人公会 → **设置** → **开启通知** → 在弹窗里点 **允许**。
2. 状态显示 **已开启，已同步** 就好了。
3. 到点时会收到“⚔️ 新的委托到了！”。iPhone 的通知上没有按钮，**点一下通知**就会打开选择卡片。

收不到的话：iPhone 的 **设置 → 通知 → 懒人公会**，确认允许通知。专注模式也可能挡住通知。

## 3. 定期备份

数据只存在这台 iPhone 上，没有账号和云同步。

- 设置 → **导出备份**，把文件存到“文件”App 或 iCloud Drive。
- 换手机、清理 Safari 数据、或者删掉主屏幕图标之前，**一定要先导出**。
- 新手机上：设置 → **导入备份**，选那个文件。
- 超过 30 天没备份，大厅会提醒你一次。

# iPhone guide

Requires **iOS 16.4+**.

1. **Add to Home Screen:** open the site in **Safari** → Share → **Add to Home Screen**. Always launch from that icon — only then do notifications and offline mode work.
2. **Notifications:** Settings → **Turn on notifications** → Allow. iPhone notifications have no buttons; tap the notification to open the quest card. If nothing arrives, check iOS Settings → Notifications → Lazy Guild, and Focus modes.
3. **Back up:** your data lives only on this phone. Use Settings → **Export backup** before switching phones or clearing Safari data, and **Import backup** to restore.
